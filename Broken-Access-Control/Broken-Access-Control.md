## Repository Structure
To keep our work organized and prevent merge conflicts, this repository uses a modular folder structure. Each vulnerability category has its own dedicated folder containing its walkthrough documentation and a sub-folder for evidence.

* `README.md` - This master document detailing our project scope and setup.
* `Broken-Access-Control/` 
  * `Broken-Access-Control.md` - Walkthroughs for all BAC-related challenges.
  * `Screenshots/` - Image evidence for BAC exploits.
* `[Next-Category-Name]/`
  * `[Category].md`
  * `Screenshots/`
